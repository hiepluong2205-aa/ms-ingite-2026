# ms-ingite-2026

Code samples and notes from the [2026 Microsoft Ignite conference](https://ignite.microsoft.com/en-US/home).

## Discover sessions

Use [Microsoft Build-CLI](https://github.com/microsoft/Build-CLI) from GitHub Copilot CLI to find Microsoft event sessions relevant to your project:

```text
/plugin install microsoft/Build-CLI
```

Restart Copilot CLI, then ask it which sessions are relevant to your project. Build-CLI currently targets Build 2026 and indexes some past events; check its catalog coverage before relying on it for Ignite 2026 sessions.

As samples are added, organize them by session code and include links to the related session when available.
